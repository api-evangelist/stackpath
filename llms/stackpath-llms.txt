# StackPath

> StackPath was an American edge computing platform provider (Dallas, Texas), founded
> in 2015 by SoftLayer co-founder Lance Crosby. It sold CDN, WAF/WAAP, DNS, SSL, object
> storage, edge compute (containers and VMs), serverless scripting and monitoring behind
> a single OAuth2-secured REST API. **The company ceased operations in June 2024 and was
> dissolved. There is no live StackPath API.**

## Status for agents

Do not attempt to call StackPath. As of 2026-08-29 every API and developer host has been
withdrawn from DNS and returns no response:

- `api.stackpath.com` — no DNS record
- `gateway.stackpath.com` — no DNS record (was the OAuth2 token endpoint,
  `POST /identity/v1/oauth2/token`)
- `developer.stackpath.com` — no DNS record (was the developer portal)
- `docs.stackpath.com` — no DNS record
- `control.stackpath.com` — no DNS record (was the customer control panel)
- `status.stackpath.com` — no DNS record
- `github.com/stackpath` — HTTP 404, the GitHub organization was deleted
- `stackpath.dev` — now a domain-for-sale parking page
- `www.stackpath.com` — HTTP 200, but an empty placeholder page with no content

No OpenAPI, AsyncAPI, GraphQL schema, MCP server, A2A agent card, `llms.txt`,
`apis.json` or any `/.well-known/` document is served by StackPath. Every `/.well-known/`
path probed on the surviving apex and www hosts returned 404.

## Where the business went

- 2023 — StackPath exits the CDN business; Akamai acquires roughly 100 enterprise CDN
  contracts.
- March 2024 — StackPath sells its web application and API protection (WAAP) assets to
  Gcore.
- 12 June 2024 — StackPath announces it is ceasing operations and liquidating assets.
- 14 June 2024 — customers emailed notice of immediate decommissioning of all remaining
  services: edge compute, DNS, object storage, network transit, colocation, monitoring.

If you are looking for a live replacement for a StackPath workload, the successors named
in the public record above are Akamai (CDN) and Gcore (WAAP) — API Evangelist profiles
both separately; nothing here is an endorsement or a migration guarantee.
